# 🚀 Career Navigator AI

An AI-powered career guidance platform designed to help students explore IT careers, understand technology paths, identify required skills, follow structured learning roadmaps, and receive personalized career advice.

---

## 📌 Overview

Choosing a technology career can be confusing for students because there are many domains, roles, technologies, skills, learning resources, and career paths to explore.

**Career Navigator AI** brings these elements together in one platform.

A student can:

- Explore IT domains
- Discover career roles
- Understand what each role does
- Explore technology paths
- Identify required skills
- Find relevant courses
- Follow structured roadmaps
- Explore companies and career opportunities
- Receive AI-powered career guidance
- Analyze skill gaps based on a target role

The goal is to help students move from:

**"I don't know what to choose."**

to:

**"I know what to learn next."**

---

## ✨ Key Features

### 🎯 Career Domain Exploration

Explore major technology domains:

- Software Development
- Data Science & Analytics
- AI & Machine Learning
- Cloud & DevOps
- Cybersecurity

---

### 💼 Role Discovery

Students can explore different technology roles and understand:

- Role description
- Career direction
- Technology paths
- Required skills
- Learning opportunities
- Roadmaps

---

### 🧭 Technology Paths

A role can have multiple technology paths.

For example:

**Backend Developer**

can lead to paths such as:

- Python + FastAPI
- Python + Django
- Python + Flask
- Java + Spring Boot
- .NET
- Node.js
- Go

Technology paths allow students to choose a specific technical direction instead of trying to learn everything at once.

---

### 🧠 Skills Exploration

The platform maintains a skill library containing technologies and concepts relevant to different career paths.

Examples include:

- Python
- SQL
- FastAPI
- Java
- Spring Boot
- React
- Docker
- AWS
- Machine Learning
- Kubernetes
- Cybersecurity
- And many more

Skills are connected to technology paths through a many-to-many relationship.

---

### 📚 Courses

Students can explore courses associated with individual skills.

---

### 🗺️ Learning Roadmaps

Technology paths contain structured learning roadmaps.

A roadmap can guide a student through:

1. Fundamentals
2. Core technology
3. APIs
4. Databases
5. Authentication
6. Testing
7. Docker
8. Projects
9. Deployment
10. Interview preparation

---

### 🏢 Company Exploration

Students can explore companies related to their career interests and roles.
