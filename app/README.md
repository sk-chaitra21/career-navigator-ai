# Career Navigator AI

## 🚀 Project Overview

Career Navigator AI is a web application that helps students explore technology domains, understand career roles, discover required skills, find learning resources, and build personalized career roadmaps.

---

## ✨ Features

- 🔐 JWT Authentication
- 🏢 Company Management
- 💻 Domain Explorer
- 👨‍💻 Role Explorer
- 🛠 Skill Management
- 📚 Course Management
- 🗺 Career Roadmaps
- ⭐ Saved Roles
- 📊 Dashboard Statistics

---

## 🛠 Tech Stack

### Backend

- Python
- FastAPI
- SQLAlchemy
- MySQL

### Authentication

- JWT
- Passlib (bcrypt)

### API Testing

- Swagger UI

## ▶️ Run the Project

```bash
git clone <repository-url>

cd CAREER_NAVIGATOR_AI

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```
